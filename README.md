# 마지막 옥상 (The Last Rooftop)

> 세상이 무너진 뒤에도, 해는 진다.

좀비 사태로 도시가 무너진 어느 날, 주인공은 좀비를 피해 높은 건물의 작은 옥상에 도착한다. 가진 것은 몸뚱이와 약간의 물자뿐. 이 옥상을 자신만의 생활 공간으로 가꾸고, 가끔은 무너진 도시로 내려가 필요한 것을 구해오면서, 혼자가 된 세상에서 하루하루를 살아간다.

이 게임은 전투 중심의 좀비 게임이 아니다. **생존, 정착, 탐험, 그리고 풍경을 감상하는 것**이 전부다. 탐사를 나가지 않고 옥상에서 조용히 하루를 보내는 것도 완전히 유효한 선택이다. 시설을 하나씩 늘려가며 옥상이 점점 따뜻한 공간으로 바뀌는 과정, 그리고 매일 다른 얼굴로 저무는 노을을 바라보는 것. 이 게임이 주고 싶은 경험은 그런 것들이다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 왼쪽 패널 | 날짜·시간·날씨, 체력/허기/갈증/피로, 보유 자원 |
| 가운데 | 옥상과 그 너머 도시를 바라보는 풍경 — 실제 게임 월드가 그려지는 곳 |
| 오른쪽 패널 | **건설 · 물자 · 일기** — 직접 결정을 내리는 곳 |

좁은 화면(모바일)에서는 좌우 패널이 화면 가장자리의 버튼을 눌러 여닫는 서랍 형태로 바뀌고, 가운데 풍경은 항상 보인다.

## 하루의 흐름 — 지켜보는 게임

이 게임은 버튼을 눌러야 시간이 가는 게임이 아니다. **탭을 열어두면 실시간으로 시간이 흐른다** (하루 ≈ 90초). 그 안에서 주인공은 알아서 먹고, 마시고, 밤이 되면 쉬면서 하루하루를 버틴다 — 플레이어는 그 모습을 지켜보다가, 중요한 순간에만 개입하면 된다.

- 다른 탭으로 옮겨갔다 돌아오면 그동안은 시간이 멈춰 있다가 그대로 이어진다.
- 탭(창)을 완전히 닫았다 나중에 다시 열면, 닫혀 있던 시간은 계산하지 않고 마지막으로 저장된 순간부터 다시 흐른다.
- 플레이어가 직접 정하는 건 **무엇을 지을지**와 **무작위로 찾아오는 사건에 어떻게 반응할지** 두 가지뿐이다.

## 생존 상태

| 상태 | 설명 |
|---|---|
| 체력 | 0이 되면 위험하다. 허기나 갈증이 오래 방치되면 서서히 깎인다. |
| 허기 / 갈증 | 시간이 지나면 조금씩 오르고, 수치가 높아지면 가진 식량·식수로 알아서 해결한다. |
| 피로 | 활동할수록 쌓이고, 심야 시간대(00:00~06:00)에는 알아서 쉬며 회복된다. |

식량이나 식수가 바닥나면 자동으로 해결되지 않으니, 탐사 기회가 왔을 때 챙겨두는 게 중요하다.

## 무작위 사건

탐사는 아무 때나 갈 수 있는 상시 메뉴가 아니다. **가끔 무작위로 찾아오는 팝업**에 반응하는 방식이다.

- **탐사 제안** — 식료품점·가정집·병원·식당 중 무작위로 3곳이 제시되고, 그중 한 곳을 골라 다녀온다. 장소마다 잘 나오는 물자의 경향은 있지만(예: 병원은 배터리·의료용품 계열), 실제로 얼마나 구할지는 매번 다르다. 가끔은 허탕을 치거나 피로만 쌓일 수도 있다.
- **낯선 방문자** — 다른 생존자가 들여보내 달라고 찾아온다. 받아들이면 보통 물자를 나눠주고 떠나지만, 때로는 그냥 스쳐 지나간다.
- **수상한 방문자** — 사람이라며 찾아오지만 확신할 수 없다. 들이면 진짜 생존자일 수도, 위장한 좀비일 수도 있다 — 결과는 그때그때 다르다.

사건이 뜬 동안은 시간이 멈춘다. 천천히 골라도 된다.

## 건설

옥상은 처음엔 텅 빈 콘크리트 바닥과 난간뿐이다. 물자를 모아 하나씩 지어나가면 된다. 오른쪽 패널의 **건설** 탭에서 시설을 고르고, 가운데 화면에서 지을 위치를 클릭하면 된다. 재료는 그 자리에서 바로 소모되지만, **완성까지는 며칠이 걸린다** — 그동안은 공사 중인 모습으로 보인다.

| 시설 | 필요 재료 | 완성까지 | 효과 |
|---|---|---|---|
| 작은 텃밭 | 목재 2, 씨앗 1 | 1일 | 시간이 지나면 자라서 수확 가능 |
| 빗물 수집기 | 천 1, 고철 1 | 1일 | 비가 오면 빗물을 모은다 |
| 작은 조명 | 고철 1, 배터리 1 | 1일 | 밤에 옥상 일부를 따뜻하게 밝힌다 |
| 텐트 | 천 2, 목재 1 | 2일 | 휴식 효과 향상 |
| 태양광 발전기 | 고철 2, 배터리 1 | 3일 | 낮에 전기를 모아 밤에 사용 |

마음에 들지 않으면(공사 중이어도) 철거할 수 있고, 재료 일부를 돌려받는다. **물자** 탭에서 보유 자원과 지어둔 시설, 공사 진행 상황을 한눈에 볼 수 있고 텃밭을 돌보거나(자라면 수확까지) 시설을 철거할 수 있다.

## 시간과 풍경

하루는 새벽-낮-노을-밤으로 이어진다. 해와 달이 서쪽 지평선을 향해 움직이고, 노을이 질 때는 하늘과 건물이 함께 주황빛으로 물든다. 밤이 되면 도시는 어두워지고, 직접 지은 조명과 태양광 시설만이 옥상을 조용히 밝힌다.

시간이 흐르고 날짜가 쌓일수록, 창밖 도시는 조금씩 변한다. 처음엔 깨진 창문과 꺼진 불빛 정도지만, 시간이 더 지나면 건물 곳곳이 무너지고 덩굴이 자라나며 자연이 도시를 되찾기 시작한다. 모든 건물이 같은 속도로 변하지는 않는다 — 어떤 곳은 금방 허물어지고, 어떤 곳은 오래 버틴다.

## 일기

그날 실제로 있었던 일(무엇을 구했는지, 무엇을 지었는지, 어떤 선택을 했는지)이 자동으로 일기에 기록된다. 지어낸 이야기가 아니라, 플레이어가 실제로 겪은 하루의 기록이다.

## 저장

상태가 바뀔 때마다 자동으로 저장되고, 창을 닫았다 다시 열어도 그대로 이어진다. 접속하면 먼저 소개 화면이 뜨고, 이어서 할지 새로 시작할지 고를 수 있다. 처음부터 다시 시작하고 싶다면 왼쪽 패널 아래의 "새 게임 시작"을 눌러도 된다(확인 후 진행).

## 시작하는 법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 바로 플레이할 수 있다.
