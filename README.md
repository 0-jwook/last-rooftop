# 마지막 옥상 (The Last Rooftop)

> 세상이 무너진 뒤에도, 해는 진다.

좀비 사태로 도시가 무너진 어느 날, 주인공은 좀비를 피해 높은 건물의 작은 옥상에 도착한다. 가진 것은 몸뚱이와 약간의 물자뿐. 이 옥상을 자신만의 생활 공간으로 가꾸고, 가끔은 무너진 도시로 내려가 필요한 것을 구해오면서, 혼자가 된 세상에서 하루하루를 살아간다.

이 게임은 전투 중심의 좀비 게임이 아니다. **생존, 정착, 탐험, 그리고 풍경을 감상하는 것**이 전부다. 탐사를 나가지 않고 옥상에서 조용히 하루를 보내는 것도 완전히 유효한 선택이다. 시설을 하나씩 늘려가며 옥상이 점점 따뜻한 공간으로 바뀌는 과정, 그리고 매일 다른 얼굴로 저무는 노을을 바라보는 것. 이 게임이 주고 싶은 경험은 그런 것들이다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 왼쪽 패널 | 날짜·시간·날씨, 체력/허기/갈증/피로, 보유 자원 |
| 가운데 | 옥상과 그 너머 도시를 바라보는 풍경 — 실제 게임 월드가 그려지는 곳 |
| 오른쪽 패널 | **탐사 · 건설 · 생활 · 물자 · 일기** — 행동을 선택하는 곳 |

좁은 화면(모바일)에서는 좌우 패널이 화면 가장자리의 버튼을 눌러 여닫는 서랍 형태로 바뀌고, 가운데 풍경은 항상 보인다.

## 하루의 흐름

1. 왼쪽 패널에서 지금 상태와 날씨를 확인한다.
2. 오른쪽 패널에서 행동을 고른다 — 탐사를 나갈지, 뭔가를 지을지, 그냥 쉴지.
3. 행동에는 저마다 걸리는 시간이 있고, 행동을 마치면 그만큼 하루의 시간이 흐른다.
4. 자고 일어나면 다음 날이 된다.
5. 그날 있었던 일은 **일기**에 자동으로 남는다.

브라우저를 켜놓기만 해도 배가 고파지는 방식은 아니다. 시간은 오직 플레이어가 어떤 행동을 할 때만 흐른다 — 가만히 화면을 보고 있다고 손해볼 일은 없다.

## 생존 상태

| 상태 | 설명 |
|---|---|
| 체력 | 0이 되면 위험하다. 허기나 갈증이 극단적으로 오래 방치되면 서서히 깎인다. |
| 허기 | 시간이 지나면 조금씩 오른다. 음식을 먹으면 내려간다. |
| 갈증 | 시간이 지나면 조금씩 오른다. 물을 마시면 내려간다. |
| 피로 | 활동할수록 쌓인다. 잠을 자면 크게 회복된다. |

수치가 조금 나쁘다고 해서 곧바로 큰일이 나지는 않는다. 다만 며칠씩 식량과 식수를 챙기지 않고 방치하면 분명히 몸이 상한다 — 탐사를 통해 다시 자원을 구해오면 된다.

## 탐사

처음엔 **편의점**만 갈 수 있고, 며칠이 지나거나 다른 곳을 충분히 둘러보면 **아파트**와 **약국**이 차례로 열린다.

| 장소 | 주로 구할 수 있는 것 |
|---|---|
| 편의점 | 식량, 음료, 씨앗 같은 생활 물자 |
| 아파트 | 천·목재 같은 건설 재료, 그리고 누군가 남긴 흔적들 |
| 약국 | 구급용품, 배터리 등 회복·전력 자원 |

각 장소에서는 짧은 사건과 두세 개의 선택지가 주어진다. 위험을 감수하면 더 많이 얻을 수도 있지만 실패할 수도 있고, 안전하게 지나칠 수도 있다 — 정답은 없다.

## 건설

옥상은 처음엔 텅 빈 콘크리트 바닥과 난간뿐이다. 물자를 모아 하나씩 지어나가면 된다. 오른쪽 패널의 **건설** 탭에서 시설을 고르고, 가운데 화면에서 지을 위치를 클릭하면 된다.

| 시설 | 필요 재료 | 효과 |
|---|---|---|
| 텐트 | 천 2, 목재 1 | 휴식 효과 향상 |
| 작은 텃밭 | 목재 2, 씨앗 1 | 시간이 지나면 자라서 수확 가능 |
| 빗물 수집기 | 천 1, 고철 1 | 비가 오면 빗물을 모은다 |
| 태양광 발전기 | 고철 2, 배터리 1 | 낮에 전기를 모아 밤에 사용 |
| 작은 조명 | 고철 1, 배터리 1 | 밤에 옥상 일부를 따뜻하게 밝힌다 |

마음에 들지 않으면 철거할 수 있고, 재료 일부를 돌려받는다.

## 생활

**생활** 탭에서는 음식 먹기, 물 마시기, 짧은 휴식, 잠자기, 옥상 정리, 그냥 시간 보내기를 할 수 있다. **물자** 탭에서는 보유 자원과 지어둔 시설을 한눈에 보고, 텃밭을 돌보거나(자라면 수확까지) 시설을 철거할 수 있다.

## 시간과 풍경

하루는 새벽-낮-노을-밤으로 이어진다. 해와 달이 서쪽 지평선을 향해 움직이고, 노을이 질 때는 하늘과 건물이 함께 주황빛으로 물든다. 밤이 되면 도시는 어두워지고, 직접 지은 조명과 태양광 시설만이 옥상을 조용히 밝힌다.

시간이 흐르고 날짜가 쌓일수록, 창밖 도시는 조금씩 변한다. 처음엔 깨진 창문과 꺼진 불빛 정도지만, 시간이 더 지나면 건물 곳곳이 무너지고 덩굴이 자라나며 자연이 도시를 되찾기 시작한다. 모든 건물이 같은 속도로 변하지는 않는다 — 어떤 곳은 금방 허물어지고, 어떤 곳은 오래 버틴다.

## 일기

그날 실제로 있었던 일(무엇을 구했는지, 무엇을 지었는지, 어떤 선택을 했는지)이 자동으로 일기에 기록된다. 지어낸 이야기가 아니라, 플레이어가 실제로 겪은 하루의 기록이다.

## 저장

행동할 때마다 자동으로 저장되고, 창을 닫았다 다시 열어도 그대로 이어진다. 처음부터 다시 시작하고 싶다면 왼쪽 패널 아래의 "새 게임 시작"을 누르면 된다(확인 후 진행).

## 시작하는 법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 바로 플레이할 수 있다.
